# Power BI E-Commerce Sales Dashboard
#Intern ID:- CITS7954
## Overview
This project presents an interactive Power BI dashboard built to analyze e-commerce sales performance.
The dashboard enables quick understanding of key business metrics such as revenue, sales trends,
category performance, and regional insights.

## Tools & Technologies
- Power BI
- Excel
- Power Query
- DAX

## Dataset
- E-commerce sales dataset (Excel/CSV)
- Fields include order date, sales, profit, product category, region, and customer segment
- Data was cleaned and transformed using Power Query

## Key Features
- KPI cards for sales, profit, and order trends
- Interactive filters for date, region, and category
- Drill-down analysis for detailed insights
- DAX measures for calculated metrics and comparisons

## Insights Derived
- Identified top-performing product categories and regions
- Analyzed monthly and seasonal sales trends
- Highlighted underperforming segments for optimization
